I'll be publishing documentation on here as well as [Github](https://github.com/marklreyes) which will show you how to set up an Apache Solr instance, crawl then index a website with Apache Nutch and finally integrating those results to the front-end with AJAX Solr.

For now, here's a list of resources which have proven to be helpful thus far:

- [Solr Tutorial](http://lucene.apache.org/solr/4_5_1/tutorial.html)
- [Nutch Tutorial](http://wiki.apache.org/nutch/NutchTutorial)
- [AJAX Solr](https://github.com/evolvingweb/ajax-solr)
- [Solr User List](http://lucene.apache.org/solr/discussion.html#solr-user-list-solr-userlucene)
- [Apache Solr 4 Cookbook](http://www.amazon.com/gp/product/B00AO2VXC8/ref=as_li_ss_tl?ie=UTF8&camp=1789&creative=390957&creativeASIN=B00AO2VXC8&linkCode=as2&tag=marlreyfroend-20)![](http://ir-na.amazon-adsystem.com/e/ir?t=marlreyfroend-20&l=as2&o=1&a=B00AO2VXC8)
