A video walkthrough of a VueJS Web App I developed for SleepScore.com. This app acts as an embeddable widget so the codebase can be hosted on any domain or mobile app. The end user is able to fill out a dynamic questionnaire with the final results ending in a series of matched products based on previous questions asked. Try the [Product Finder](https://www.sleepscore.com/product-finder) out today!

## Core Technologies

- Vue CLI
- Vuidget - Vue.js embeddable widget
- Bootstrap 4, Bootstrap Vue
- WordPress
