1. In terminal run this command:

```
    open /Applications/Xcode.app/Contents/Developer/Platforms/iPhoneSimulator.platform/Developer/Applications/iPhone\\ Simulator.app_
```

2. Once opened, right click on the app and select 'Keep in Dock'.

Thanks to [Stackoverflow](http://stackoverflow.com/questions/10379622/how-to-run-iphone-emulator-without-starting-xcode)
