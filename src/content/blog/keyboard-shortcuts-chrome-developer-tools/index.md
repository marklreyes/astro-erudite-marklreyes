## Chrome Developer Tools: Search or navigate to files, methods or line numbers. Shortcuts for text search and beyond.

**To search scripts, stylesheets and snippets by filename you can use:** __Ctrl + O (Windows)_ _Cmd + O (Mac OSX)__

**To perform a text search within the current file you can use:** _Ctrl + F (Windows)_ _Cmd + F (Mac OSX)_

**To do a text search across all files you can use:** _Ctrl + Shift + F (Windows)_ _Cmd + Opt + F (Max OSX)_

**If you need to dig down deeper, it's possible to filter for or navigate to a particular JavaScript function/method or CSS rule when viewing a file using:** _Ctrl + Shift + O (Windows)_ _Cmd + Shift + O (Mac OSX)_

**The tools also support going to a specific line-number within the Sources editor. To launch the line number dialog when viewing a file you can use:** _Ctrl + L (Windows)_ _CMD + L (Mac OSX)_

_Cmd/Ctrl + F works across tabs other than Sources such as Resources or Network. If you check the 'filter' option when searching, this will filter down the list of results to only those containing the terms you were looking for._

_You can also switch between tabs using Cmd + \[ and Cmd + \]_

_If you are editing a script and select some code, you can evaluate it in the console right away using Ctrl + Shift + e_
